# Working rules for this research project

- Current scope includes the human-requested reproducibility, configurable worlds/avatars, instance isolation and detailed documentation pass, plus the explicit Talos naming, MIT licensing and GitHub source push authorized on 2026-10-22. Read docs/STATUS.md and docs/PHASES.md before making changes. This does not authorize training, object-interaction research or distribution of excluded assets.
- Do not begin the next phase until the human explicitly passes the preceding verification gate. Never record yourself or another AI as the human reviewer.
- A phase gate reduces risk; it is not a guarantee of future correctness. Reopen affected gates after incompatible changes.
- Keep source MetaHuman projects and assets unchanged. The isolated runtime harness loads external Content but must not save it.
- Keep policy observations separate from privileged diagnostic fields. Record all supplied controllers, pretraining, demonstrations, and task assistance.
- Report client unit tests, engine builds, headless integration checks, rendered integration checks, and human review separately. Do not describe mocks or valid file formats as successful live simulation evidence.
- Do not claim learned locomotion, intelligence, brain equivalence, or consciousness from the scripted interface diagnostic.
- Preserve protocol compatibility or explicitly version breaking changes. Fail on uncertain mutation outcomes instead of blindly retrying actions.
- Source distribution excludes tokens, logs, private machine paths, run artifacts, engine binaries, and the personal avatar. Public licensing and asset distribution are human decisions.
- Human approval to pass a phase is separate from approval to publish it externally.
